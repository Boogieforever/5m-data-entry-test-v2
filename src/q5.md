# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
_(The kernel is the manager in the operating system that handle requests whenever the application needs access to the computer cpu, memory, file system and hardware device connected to this computer.)_

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
_(After WSL is installed, the windows OS kernel is still the primary kernel. However it is hosting the linux kernel as a guest kernel to handle linux applications requests. However they are not totally independent as they are sharing the same hardware, network ports and files systems which are handled by Windows OS.)_

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
_(Terminal emulator is a graphical user interface for user easy access to the computer operating system resources. Example is MS Windows 11 GUI. Shell is the command line interface for user access to the computer OS resources. Example is the Command Prompt or Powershell)_
